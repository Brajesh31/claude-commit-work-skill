# Commit Work

A safe workflow for staging intended changes, splitting unrelated work, and creating reviewable Git commits.

## Capabilities

- Inspect working tree and staged changes.
- Group modifications into logical commits.
- Stage explicit files or selected hunks.
- Review staged diffs for accidental changes and secrets.
- Write Conventional Commit messages.
- Run relevant checks and verify completed commits.

## Included reference

- `references/commit-message-template.md`: a reusable commit message structure.

## Usage

Use when asked to stage, split, prepare, or commit work. Keep commits coherent and avoid including unrelated changes. The skill requires clear reporting of commit hashes, checks, and remaining work.
